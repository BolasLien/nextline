Nextline 品牌方向：三選一

NX-146。三個方向用同一塊看板、同一批真實的票比較。往下捲依序是：推薦、三個 logo 對照、各方向的 logo／色彩／字體／圖示／語氣／看板（淺色、深色）。

推薦 B「接力」：它的 logo 本身就在講「人和 agent 一起推進」，畫面又最不像工程工具。

  1. logo 直接講產品主張。實心圓是人、空心圓是 agent，兩個走在同一條線上往前。定位頁原則 1「人和 agent 對等」不用解釋，看圖就懂。
  2. 跟競品拉開距離。Linear、Plane、GitHub Projects 都是冷色、工程感的介面。A「定線」最穩，但站在它們旁邊認不出來；B 的陶土色和米白底，一眼就看得出是 Nextline。
  3. 適合主推的人和市場。一人公司每天要開好幾次看板，溫和的語氣比較耐看；繁中介面文字寫成像合作夥伴在講話，比工程用語親切。按月收費要讓人信任，所以狀態色維持標準的藍、琥珀、綠、紅，看狀態跟其他工具一樣準。
  4. 想要更搶眼可以改選 C。C「換行」最有個性，把主色直接定義成「輪到你」，最貼近原則 2。代價是粗框和硬陰影會讓長時間使用的畫面比較吵，深色模式也比較刺眼。
定位頁原則
A 定線
B 接力
C 換行
1. 人和 agent 對等
A兩條線代表人和 agent，要解釋才看得懂
B★ 實心圓（人）＋空心圓（agent）同一條線，看圖就懂
C強調「下一步」，人和 agent 的關係沒有畫出來
2. 狀態一眼可見
A狀態色最乾淨、密度最高
B狀態用膠囊徽章＋色點；待驗收欄加虛線框
C★ 主色就是「等你」，最醒目
3. 看板是主畫面
A一屏塞得下最多卡片
B★ 卡片和欄位的層次最好分，第一次看也不吃力
C粗框讓卡片很搶眼，但卡片多時畫面比較擠
4. 看得到、停得了
A停止圖示中性，不夠醒目
B語氣會說清楚 agent 現在在做什麼
C錯誤和停止的對比最強
5. 打開就能用
A文字精準但偏冷，像說明書
B★ 空狀態直接告訴你第一步按 C
C文字短又俏皮，第一次用的人可能要多想一下
看板上的票、負責人和代做 agent 都是 Nextline 裡真實的票；欄位和 session 狀態為了示範各種情況有調整，不是目前的實際狀態。英文字型建議（Inter、Nunito、Space Grotesk、JetBrains Mono、IBM Plex Mono）沒有內嵌，本頁用 fallback 的系統字型顯示。
