從 Linear 換過來

工具前綴換掉就好，例如 Claude Code 裡 mcp__linear__list_issues → mcp__nextline__list_issues。下表的參數 Nextline 不支援時，多半是直接忽略、不會報錯，所以 agent 不會因此壞掉，但也不會有效果。

Nextline 沒有指派、標籤、優先度、估點、父子票、文件，也不能刪除。依賴這些欄位的流程要改寫。
