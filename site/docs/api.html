網址

跑法API 網址
Node 本機http://127.0.0.1:3000/api
Node 放在 HTTPS 代理後面https://你的網域/api
Cloudflare Workershttps://<你的 Worker>.workers.dev/api

文件裡的範例都用 Node 本機的網址。

認證

每個請求都要帶 token：

```sh curl -H "Authorization: Bearer $NEXTLINE_API_TOKEN" http://127.0.0.1:3000/api/issues ```
  • token 怎麼來：Node 跑法用 npm run --silent selfhost:token 產生（見產生 token）；Cloudflare 跑法是 Worker secret API_TOKEN。
  • 沒帶、帶錯、或已經換掉的舊 token，一律回 401。
  • /api 只收 token，不收網頁登入的 cookie；網頁也不收 token。
  • 只有一組 token，所有 agent 共用、權限相同。author、actor 是記錄用的文字，不是身分驗證。

請求與回應

  • 請求內容與回應都是 JSON（Content-Type: application/json）。
  • 時間是 ISO 8601，存進去前一律轉成 UTC，例如 2026-11-02T08:29:53.024Z。日期（due_date）是 YYYY-MM-DD。
  • PATCH 只改有帶的欄位；可以清空的欄位帶 null。
  • 帶了不認得的欄位會回 400，不會改任何資料。回應多帶 unknown_fields（不認得的欄位）和 allowed_fields（這個路徑可以帶的欄位）；照 MCP 習慣寫的 state、dueDate 會提示改成 REST 的名稱。
  • 沒有刪除：不要的票改成 Canceled 或封存。

REST 與 MCP 的欄位名稱

同一件事，REST 用 snake_case，MCP 照 Linear MCP 用 camelCase。混用時 REST 會回 400 告訴你該用哪個名稱：

要改什麼REST（/api）MCP（save_issue）
狀態statusstate
到期日due_datedueDate
Projectproject_id（數字 id）project（名稱或 id）
Sprintsprint_id（數字 id）cycle（編號、名稱或 id）
blocked byPOST /api/issues/:ref/blockers 的 blocked_byblockedBy

MCP 對不認得的參數照 Linear MCP 的習慣直接忽略，REST 則回 400。

票號 :ref

路徑裡的 :ref 收 NX-12 或 12，不分大小寫。從其他系統搬進來的票如果有舊編號（legacy_identifier，格式像 ABC-150），也可以用舊編號查。

分頁

列表類的路徑用 limit（預設 50、最多 200）與 offset。回應帶 has_more，是 true 就把 offset 加上 limit 再拿下一頁：

```json { "issues": [ ... ], "limit": 50, "offset": 0, "has_more": true } ```

錯誤

錯誤一律是 { "error": "說明" }，說明是中文：

狀態碼什麼時候
400內容不是 JSON 物件、帶了不認得的欄位、缺必填欄位、值的格式不對、參照的 Project 或票不存在
401沒有有效的 token
404票、comment、Project 不存在，或沒有這個路徑
405這個路徑不支援這個方法；Allow 標頭列出支援的方法
409資料重複（例如 Project 名稱），或變更紀錄不能還原；會多帶相關資料的 id，見各頁說明
```json { "error": "status 必須是 Backlog、Todo、In Progress、In Review、Done、Canceled 其中之一" } ``` ```json { "error": "不認得的欄位：state。state 請改用 status（REST 用 snake_case，例如 status、due_date）。可以帶的欄位：title、description、status、project_id、sprint_id、due_date、archived、position、before、after、actor", "unknown_fields": ["state"], "allowed_fields": ["title", "description", "status", "project_id", "sprint_id", "due_date", "archived", "position", "before", "after", "actor"] } ```

健康檢查

GET /health 不用 token，只回服務與資料庫是否正常，不帶任何資料：

```json { "ok": true, "db": "ok" } ```

資料庫讀不到時回 503 與 { "ok": false, "db": "error" }。
