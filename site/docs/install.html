需要什麼

  • Node 22.23.4（repo 的 .nvmrc、.node-version 寫的就是這版；可依 Node 官方安裝方式取得）。只驗證過這一版，其他版本啟動時會直接拒絕。
  • git、終端機。

安裝

```sh git clone https://github.com/BolasLien/nextline.git cd nextline npm ci npm run build export NEXTLINE_DATA_DIR="$HOME/.local/share/nextline" # 資料放這裡（這也是預設值） npm run selfhost:init # 設定登入密碼 npm start ```

selfhost:init 會在終端機問你要設的登入密碼（12～256 個字元，輸入時不顯示）。沒有公開的註冊頁，這組密碼就是唯一的登入方式。

在腳本、CI 或讓 agent 幫你架這種沒有終端機可以輸入的地方，加 --password-stdin 從標準輸入讀密碼（不要把密碼放在命令列參數）：

```sh printf '%s\n' "$NEXTLINE_PASSWORD" | npm run selfhost:init -- --password-stdin ```

建議第一次 npm start 前就把 NEXTLINE_OWNER_NAME 設成你自己的名字（見下面的可以調的設定）。待驗收的票只有這個名字回覆才會交回 agent；預設的「你」很常見，agent 剛好用「你」當 comment 作者時也會把票交回去。

Node 22.23.4 的 node:sqlite 啟動時會顯示「實驗性功能」的提示，這是正常的。

第一次登入

打開 http://127.0.0.1:3000，輸入剛剛設的密碼就能開票、拖拉、留言。

請用 127.0.0.1:3000，不要換成 localhost：服務會核對網址的主機名稱，沒改設定時用 localhost 會被拒絕。
  • 登入有效 12 小時，過期後重新登入會回到原本那一頁。
  • 桌面版在側欄、手機版在「更多」裡可以登出。
  • 登入每分鐘最多試 5 次（成功也算），重啟服務也不會清掉這個限制。

資料放在哪裡

所有資料（票、comment、密碼雜湊、token 雜湊）都在 $NEXTLINE_DATA_DIR/nextline.sqlite，跟程式碼分開放：

  • 這個資料夾只給 Nextline 用：權限是 0700，資料庫是 0600。裡面有其他檔案或捷徑時會拒絕啟動。
  • 放在本機磁碟，不要用網路磁碟。
  • 按 Ctrl+C 正常關機。重跑 selfhost:init 會保留密碼、token 和既有資料。

可以調的設定

都用環境變數，npm start 前設定：

變數說明
NEXTLINE_DATA_DIR資料資料夾。預設 ~/.local/share/nextline
NEXTLINE_HOST綁定的 IP（要寫 IP，不能寫主機名稱）。預設 127.0.0.1；不是本機位址時必須走 HTTPS 代理
NEXTLINE_PORT連接埠。預設 3000
NEXTLINE_PUBLIC_URL對外網址。預設由 host、port 組成；放到伺服器上時設成 https://你的網域
NEXTLINE_TRUSTED_PROXIES反向代理的 IP，逗號分隔。預設沒有；HTTPS 模式必填
NEXTLINE_OWNER_NAME網頁上的人叫什麼：你在網頁寫的 comment、移票紀錄都記這個名字，只有這個名字回覆待驗收的票會交回 agent。預設「你」

要讓別台裝置連進來，見架在伺服器上（HTTPS）。

改程式的開發模式

完成上面的建置與初始化後，npm run dev 會同時啟動 Node（3000）與 Vite（5173），開 http://127.0.0.1:5173，前後端改了都會自動重載。開發模式的 MCP 網址是 http://127.0.0.1:5173/mcp。
