網頁介面沒有 Sprint。需要依週期整理票的 agent 或腳本可以用這組 API；MCP 對應的是 list_cycles 與 save_issue 的 cycle。
方法與路徑做什麼
GET /api/sprints列出，依編號新到舊；回 { "sprints": [...] }
POST /api/sprints新增，回 201
GET /api/sprints/:id讀一個
PATCH /api/sprints/:id修改名稱與起訖時間

欄位

欄位說明
id數字
number第幾期，不可重複
name名稱，可以是 null
starts_at、ends_at起訖時間（ISO），結束要晚於開始
linear_id搬資料用的外部 id
created_at建立時間

新增

內容：number、starts_at、ends_at 必填；name、linear_id、created_at 選填。編號重複回 409。

```sh curl -X POST http://127.0.0.1:3000/api/sprints \ -H "Authorization: Bearer $NEXTLINE_API_TOKEN" \ -H "Content-Type: application/json" \ -d '{"number":1,"starts_at":"2026-11-16T00:00:00Z","ends_at":"2026-11-23T00:00:00Z"}' ```

修改

內容：name（null 清掉）、starts_at、ends_at。票要放進 Sprint，用票的 sprint_id。
