先準備

  1. Nextline 已經在跑（見安裝與第一次登入）。
  2. 產生 token 並放進環境變數 NEXTLINE_API_TOKEN（見產生 token）。

設定

在 ~/.codex/config.toml 加上：

```toml [mcp_servers.nextline] url = "http://127.0.0.1:3000/mcp" bearer_token_env_var = "NEXTLINE_API_TOKEN" ```

Codex 會讀這個環境變數，自己加上 Authorization: Bearer …。Nextline 放在伺服器或 Cloudflare 上時，把網址換成自己的 https://…/mcp。

確認連上了

```sh codex mcp list ```

可用的工具與參數見 MCP 工具。改票時帶 actor、寫 comment 時帶 author，變更紀錄才分得出是哪個 agent 改的。

參考：Codex 的 MCP 文件（bearer_token_env_var）。
