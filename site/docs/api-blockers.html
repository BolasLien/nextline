方法與路徑做什麼
GET /api/issues/:ref/blockers擋住這張的票、這張擋住的票
POST /api/issues/:ref/blockers加一張擋住這張的票
DELETE /api/issues/:ref/blockers/:blockerRef拿掉

列出

GET/api/issues/:ref/blockers 回 { "blocked_by": [...], "blocks": [...] }，每一項有 identifier、number、legacy_identifier、title、status。讀一張票也會帶這兩個欄位。

加 blocked by

POST/api/issues/:ref/blockers 新加入回 201，本來就有回 200；內容都是更新後的列表。

內容

blocked_by票號 · 必填

擋住這張的票，NX-3、3 或舊編號。擋自己、或票不存在回 400。

actorstring

預設 api。

請求

curl -X POST -H "Authorization: Bearer $NEXTLINE_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"blocked_by":"NX-11","actor":"my-agent"}' \
  http://127.0.0.1:3000/api/issues/NX-13/blockers

拿掉 blocked by

DELETE/api/issues/:ref/blockers/:blockerRef 回更新後的列表。本來就沒有這個關係回 404。誰拿掉的用查詢參數 ?actor= 帶（預設 api）。

請求

curl -X DELETE -H "Authorization: Bearer $NEXTLINE_API_TOKEN" \
  "http://127.0.0.1:3000/api/issues/NX-13/blockers/NX-11?actor=my-agent"
