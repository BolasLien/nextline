忘記網頁密碼

由能操作伺服器的人，在原始碼資料夾、同一個 NEXTLINE_DATA_DIR 下執行：

```sh npm run selfhost:password ```
  • 會在終端機問新密碼（12～256 個字元）。
  • 所有已登入的 session 都會失效，要重新登入。
  • 不會動到 agent token。

Nextline 沒有寄信重設、也沒有遠端重設密碼。要用腳本設定密碼時（第一次 selfhost:init 或 selfhost:password 都可以），加 --password-stdin 從標準輸入讀，不要把密碼放在命令列參數：

```sh printf '%s\n' "$NEW_PASSWORD" | npm run selfhost:password -- --password-stdin ```

換 agent token

```sh export NEXTLINE_API_TOKEN="$(npm run --silent selfhost:token)" ```
  • 新 token 只顯示這一次，服務端只存 SHA-256 雜湊。
  • 舊 token 立刻失效，下一個請求就會回 401。
  • 更新每個 agent 用的環境變數，然後重啟 Claude Code、Codex 等 client。

所有 agent 共用這一組 token，沒有個別權限，所以只要懷疑外洩就換一組。

Cloudflare 跑法

人的登入交給 Cloudflare Access，Nextline 沒有密碼。換 token 就是重新設定 Worker secret：

```sh npx wrangler secret put API_TOKEN ```
